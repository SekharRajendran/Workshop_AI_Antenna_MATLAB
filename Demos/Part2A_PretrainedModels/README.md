# Part 2A: Pretrained antenna models

Open [demo_part2a_ai_antenna_optimization.m](demo_part2a_ai_antenna_optimization.m)
in MATLAB R2026b's Live Editor. Set the current folder to this directory and work
through the sections.

The example explores the bandwidth–gain trade-off for a 5.9 GHz patch on Teflon
using `AIAntenna` and `paretosearch`, then compares selected designs. The `.m` file
is the current source and contains explanatory text and saved output. No local
input dataset is required.

Use Antenna Toolbox and Global Optimization Toolbox. MATLAB dependency analysis
also identifies Optimization Toolbox and Statistics and Machine Learning Toolbox.
The pretrained-model visualizations shown use R2026b functionality. Stay within the
reported tunable ranges and validate any final design using EM or measurements.

Continue with the [Part 2A exercises](../../Exercises/README.md) from the repository
root's Exercises folder.
