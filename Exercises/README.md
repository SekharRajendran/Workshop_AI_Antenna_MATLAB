# Hands-on exercises

Open each `.m` file in MATLAB's Live Editor and set the current folder to its
directory. Complete the `% __` blanks before running the corresponding section.
The blanks are intentional; use the solution files after attempting the exercise.

## Part 2A: Pretrained antenna models

- [Exercise](Part2A_PretrainedModels/exercise_part2a_pretrained_antennas.m)
- [Solution](Part2A_PretrainedModels/exercise_part2a_pretrained_antennas_solution.m)

Explore patch and horn designs, tunable parameters, and AI performance queries.
Use a compatible MATLAB release with Antenna Toolbox; R2026b is the reference.

## Part 2B: Pattern reconstruction

- [Exercise](Part2B_PatternReconstruction/exercise_part2b_pattern_reconstruction.m)
- [Solution](Part2B_PatternReconstruction/exercise_part2b_pattern_reconstruction_solution.m)

Reconstruct sector and rhombic patterns and import an MSI/Planet file. The two
slice datasets and `Test_file_demo.pln` are included beside the exercise.

- [MATLAB activity](Bonus_Optimization/exercise_bonus_antenna_optimization.m)
